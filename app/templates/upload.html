Required CSV Column Specification

Your uploaded CSV header row must contain the following columns (order-independent, case-insensitive):

Column Name Data Type Sample Value Rules & Description
student_id String STU1001 Unique university identifier. Used for clean database upserts.
name String Sarah Connor Full name of the student.
